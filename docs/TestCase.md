# Initial House 测试用例设计

## 1. 测试目标

本文档用于指导 `initial_house` 模组的功能测试与原版游戏回归测试，覆盖初始房屋生成、出生点缓存、玩家出生与重生、结构保护半径、持久化数据和基础兼容性等场景。

当前项目没有独立的 JUnit 测试目录，本文档中的用例默认按手动测试设计，也可以结合 Forge 开发环境、服务端日志、游戏内指令和存档文件进行辅助验证。

## 2. 测试范围

### 2.1 模组本体测试范围

- 模组启动、注册与 Mixin 加载。
- 主世界出生点区块缓存与服务端关闭清理。
- 初始房屋结构在出生点区块生成。
- 结构模板选择、旋转、镜像、枢轴偏移和数据标记处理。
- 首次进入世界与死亡重生时的精确出生点逻辑。
- 已处理玩家 UUID 的世界级持久化。
- 初始房屋附近阻止其他结构生成的保护半径逻辑。

### 2.2 原版游戏回归测试范围

- 主世界、下界、末地的加载和切换。
- 原版随机出生偏移行为。
- 床和重生锚的重生行为。
- 出生点保护半径外的原版结构生成。
- 不同地形上的区块生成、地形高度和存档读写。

## 3. 测试环境建议

| 项目 | 建议值 |
| --- | --- |
| Minecraft 版本 | 1.20.1 |
| Mod Loader | Forge |
| Java 版本 | Java 17 |
| 启动方式 | `./gradlew runClient`、`./gradlew runServer`、`./gradlew runGameTestServer` |
| 测试模式 | 单人开发环境、局域网或专用服务端 |
| 日志检查 | 启动日志、世界加载日志、崩溃报告、服务端控制台 |

## 4. 通用测试准备

1. 构建模组或启动开发环境，确认游戏可以正常进入主菜单。
2. 清理或备份测试存档，避免旧存档数据影响首次进入、结构生成和持久化验证。
3. 每个配置类用例建议使用独立世界，或在测试前删除对应世界目录后重建。
4. 修改服务端配置后，需要重启世界或服务端，确保 Forge Server Config 已重新加载。
5. 需要定位结构时，可以使用 `/locate structure initial_house:initial_house` 辅助观察。
6. 需要观察坐标时，可以打开 F3，或使用 `/tp`、`/setworldspawn`、`/kill` 等指令辅助。
7. 需要验证原版结构时，可以使用固定种子、多次新建世界或 `/locate structure minecraft:village` 等指令辅助。

## 5. 配置维度

| 配置项 | 默认值 | 影响范围 | 重点风险 |
| --- | --- | --- | --- |
| `INITIAL_HOUSE_STRUCTURES` | `["initial_house:initial_house"]` | 初始房屋模板候选列表 | 空列表、资源不存在、资源 ID 非法 |
| `INITIAL_HOUSE_PIVOT_X` | `4` | 模板 X 轴放置偏移 | 房屋偏离出生点、嵌入地形 |
| `INITIAL_HOUSE_PIVOT_Y` | `1` | 模板 Y 轴放置偏移 | 房屋悬空、深埋、玩家卡方块 |
| `INITIAL_HOUSE_PIVOT_Z` | `4` | 模板 Z 轴放置偏移 | 房屋偏离出生点、嵌入地形 |
| `DISABLE_SPAWN_POINT_RANDOM_SHIFTING` | `false` | 玩家首次出生和无有效重生点时重生 | 错误覆盖原版出生/重生逻辑 |
| `SPAWN_POINT_SHIFT_X` | `0` | 精确出生 X 偏移 | 玩家出生位置异常 |
| `SPAWN_POINT_SHIFT_Y` | `0` | 精确出生 Y 偏移 | 玩家窒息、掉落、悬空 |
| `SPAWN_POINT_SHIFT_Z` | `0` | 精确出生 Z 偏移 | 玩家出生位置异常 |
| `PREVENT_STRUCTURES_GENERATE_IN` | `5` | 初始房屋周边原版结构生成抑制半径 | 误伤初始房屋或过度抑制原版结构 |

## 8. 缺陷记录建议

执行测试时建议记录以下信息：

- 测试用例编号。
- Minecraft、Forge、Java 和模组版本。
- 世界种子、维度、坐标和关键配置。
- 复现步骤、实际结果和预期结果。
- 客户端日志、服务端日志、崩溃报告和截图。
- 是否可以通过删除配置、删除存档或恢复默认配置回滚。

## 9. 验收标准

- 默认配置下，游戏可以正常启动、创建世界、进入世界、保存并重新进入。
- 默认配置下，出生点附近可以生成初始房屋，且 `/locate structure initial_house:initial_house` 可定位到合理位置。
- `DISABLE_SPAWN_POINT_RANDOM_SHIFTING=false` 时，不强制覆盖原版出生随机偏移。
- `DISABLE_SPAWN_POINT_RANDOM_SHIFTING=true` 时，首次进入和无有效重生点的重生位置符合配置。
- 有效床和有效重生锚不被错误覆盖。
- 初始房屋保护半径内的其他结构生成抑制符合配置，保护半径外原版结构正常生成。
- 服务端重启后，出生点缓存和玩家持久化数据行为稳定。
- 负例配置不应导致无法诊断的崩溃；若当前版本会崩溃，应形成明确缺陷记录。
